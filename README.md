📻 About

Airwave Tamil is a simple, modern internet radio experience dedicated exclusively to Tamil-language radio stations.

Discover Tamil radio from different places, find your favourite stations, and enjoy listening through a clean, easy-to-use interface.

Designed with support for both Tamil and English, Airwave Tamil brings the world of Tamil radio together in one place.

✨ Features

- Tamil-only radio catalogue: Discover Tamil-language stations without unrelated radio listings.
- Search: Find stations using their names and available metadata.
- Surprise Me: Discover a random station from your current filtered results.
- Favourites: Save the stations you love.
- Hide stations: Remove stations you don't want to see and restore them whenever you wish.
- Import & Export: Back up and restore your favourites and hidden stations using JSON files.
- Bilingual interface: Switch between Tamil and English.
- Five visual themes: Midnight Purple, AMOLED Black, Ocean, Light and Forest.
- Recent stations: Easily revisit previously played stations.
- Mini-player: Keep playback controls accessible while browsing.

🎧 Getting Started

1. Visit "Airwave Tamil" (https://prasannaone.github.io/Airwave-Tamil/).
2. Browse or search for a Tamil radio station.
3. Select a station to start listening.
4. Save favourites or hide stations you don't like.
5. Customise your experience through Settings.

An internet connection is required to stream radio stations.

💾 Your Stations, Your Choice

Airwave Tamil gives you control over your listening experience.

- Add stations to Favourites.
- Hide unwanted stations from Explore.
- Restore hidden stations whenever you want.
- Export your saved preferences as a JSON backup.
- Import your backup later without replacing the bundled catalogue.

Imported stations are checked for Tamil-language metadata before being accepted.

🌐 Technology & Catalogue

Airwave Tamil is a standalone HTML application designed to work with GitHub Pages.

The bundled station catalogue uses data from "Radio Browser" (https://www.radio-browser.info/).

Browsing the bundled catalogue does not require a server request. However, playing radio streams requires an internet connection and depends on each station's stream availability.

🚀 Run Your Own Copy

Want to host your own version?

1. Fork or create a GitHub repository.
2. Upload the HTML file to the repository's root directory.
3. Rename it to "index.html".
4. Open Settings → Pages.
5. Select Deploy from a branch.
6. Choose the "main" branch and "/ (root)" folder.
7. Save and wait for GitHub Pages to publish your site.

No build process or package installation is required.

🔒 Privacy & Storage

Your favourites, hidden stations, recent history, theme and language preferences are stored locally in your browser.

They are not automatically synchronised between devices. Export your backup before clearing browser data or switching devices.
